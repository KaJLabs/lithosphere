# Validator setup

The canonical validator onboarding guide is maintained at
[docs.litho.ai](https://docs.litho.ai/docs/testnet/validators). Its source is
[`content/docs/testnet/validators.mdx`](../../content/docs/testnet/validators.mdx)
in this repository.

Use the network table in that guide before running any command. The current
production network is LITHO Mainnet with Cosmos chain ID
`lithosphere_9005-1` and EVM chain ID `9005`; older examples using `700777`
refer to Makalu and must not be used for mainnet.
