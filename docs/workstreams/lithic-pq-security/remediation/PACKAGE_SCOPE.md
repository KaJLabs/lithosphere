# R8 Package Scope

This archive contains only the active R8 normative specifications, executable
format, authorization, sequence, registry, emergency migration and transparency
references and vectors, frozen standards/baseline/dependency evidence, and the
Autha R7 design re-review input.

Earlier R0-R7 handoffs, matrices, and superseded build/verification scripts are
excluded to prevent accidental implementation of superseded semantics. The R7
Autha report is retained only as the review input for R8 closure.

The package is an unsigned design re-review candidate. It does not authorize
Makalu consensus activation, an explorer PQ badge, any mainnet change, or
dependency/implementation acceptance.
