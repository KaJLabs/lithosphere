--------------------------------------------------------------------------------
  reentrancy-benign / reentrancy-events
      lockTokens does the external token call (safeTransferFrom on source,
      burnFrom on dest) before `nonce++` and the TokensLocked event. The
      function carries OZ `nonReentrant`; the only state written after the call
      is the monotonic nonce and an event. No funds-affecting state is mutated
      post-call. Flagged for audit confirmation, not believed exploitable.

  timestamp
      `block.timestamp >= lastCapReset[token] + 86400` drives the 24h daily-cap
      window. A +/-15s validator drift cannot meaningfully move a 24h boundary.
      See threat model L5.

  assembly
      Inline asm is the standard ECDSA `recover()` signature-split (r/s/v). See
      threat model open-question #1 (EIP-712 migration consideration).

  naming-convention
      `_validators` / `_signaturesRequired` leading-underscore params. Cosmetic.

  missing-zero-check (setPauseGuardian)
      INTENTIONAL: passing address(0) is the supported way to CLEAR the pause
      guardian. A zero-check would remove that capability. Owner-only setter;
      worst case of a wrong value is an inability to fast-pause until corrected
      (the owner can always pause directly). Not a defect.
